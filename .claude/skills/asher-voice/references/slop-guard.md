# Slop guard

Self-contained, so this skill works even when no-ai-slop isn't loaded. Condensed from no-ai-slop, with Asher-specific overrides. Fix silently; don't report what changed unless asked.

## Words to cut

**Banned outright:** delve, foster, leverage, utilize, facilitate, empower, streamline, robust, cutting-edge, paradigm shift, game-changer, this is huge, this changes everything, tapestry, realm, beacon, multifaceted, meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving, unlock (as a metaphor), journey (as a corporate metaphor).

**Empty phrases:** it's worth noting, it's important to note, at the end of the day, when it comes to, at its core, in today's world, in the age of, the reality is, in terms of, with regard to, in order to, going forward, in this article, let's dive in, I'm excited to share.

**Often-empty adverbs:** just, literally, simply, truly, fundamentally, importantly, crucially, inherently, inevitably. Cut when they add nothing.
- **Override:** "genuinely", "honestly", "truthfully", "actually" are Asher's honesty markers. Keep them when they mark a real admission or emphasis.

## Patterns to cut

| Pattern | Example | Fix | Asher override |
|---|---|---|---|
| Binary contrast | "It's not X. It's Y." | State Y directly | None - cut it |
| Throat-clearing | "Here's the thing", "Let me be clear" | Start with the point | None |
| Faux-insight setup | "What nobody tells you...", "Most people get this wrong" | Make the claim stand alone | None |
| Colon reveal | "The best part: it learns." | Plain sentence | None |
| Superficial -ing tail | "..., highlighting the importance of" | Say the actual consequence | None |
| Importance puffery | "marks a pivotal moment" | State the fact | None |
| Interpretive metadiscourse | "That last part matters more than it sounds" | Delete; let the content show it | None |
| Weasel attribution | "Experts agree", "studies show" | Name the source or cut | None |
| Synonym cycling | agent / assistant / tool for the same thing | Repeat the clear word | None |
| Negative listing | "Not a X. Not a Y. A Z." | Say Z | None |
| Vague change | "Something shifted." | Dramatise what changed | Confirmed by Asher as slop |
| Rhetorical setups | "What if I told you...", "Plot twist:", "Think about it:" | Make the point | Question **headers** he'd actually ask himself stay |
| Dramatic fragmentation | "That's it. That's the whole thing." | Full sentence | His fragments and rule-of-three stay when they follow a real build-up. Cut stacked fragments with no build-up. |
| Robotic rhythm | Every paragraph same length and shape | Vary | None |
| Fake-profound kicker | New cute metaphor as the last line | Delete; end on the last concrete sentence | A **callback** to an image already in the post stays |
| Summary-recap ending | "In conclusion...", restating the post | End on the last real point | Short spoken recap allowed in teaching YouTube scripts only |
| Formatting slop | Emoji headers, bold mid-sentence, bullets for prose | Format follows content | None |
| Em dashes | — | Hyphen with spaces, comma, colon, or split | **Zero**, stricter than no-ai-slop |

## Two tests

- **Portability test:** if a sentence could move unchanged into someone else's post, it's filler. Replace it with something only Asher could say, or cut it.
- **Scene-detail protection:** slop editing tends to trim "unnecessary" detail for concision. In Asher's drafts, the scene detail is the point. Trim clutter inside sentences, never the scene.
